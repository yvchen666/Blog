## 复现错误时无编辑按钮

找到文件

editmainwindow.cpp

在supportType函数中

```cpp
        if (deviceType == QtAoi::Virtual3D || deviceType == QtAoi::AIS430 || deviceType == QtAoi::AIS431_D || deviceType == QtAoi::Virtual3D
               || deviceType == QtAoi::AIS330 || deviceType == QtAoi::AIS330_L)
        {
            QString spifp = QDir::homePath() + "/.config/Leichen" + QDir::separator() + QLatin1String("supportSpi.ini");
            if (QFileInfo(spifp).exists()) {
                return QtAoi::SupportSPI;
            } else {
                return QtAoi::Support3D;
            }
        }
```

查看到支持的虚拟相机的类型**Virtual3D**

在**Hardware.xml**文件中修改虚拟相机类型为Virtual3D

**SPI设备**，所以需要在/home/aoi/.config/Leichen目录下创建文件supportSpi.ini 重启软件正常显示

**PS：**

在复现时 版本不对应时，可以先切换到develop分支 看看问题能否复现

如果不能复现，先在坚果云上下载对应版本的软件进行复现

最好不要直接编译版本，花费时间长。

updateComponent函数耗时过长

![image-20240725191705064](/images/notes/assets/2.15.3.XJira/image-20240725191705064.png)

现象：使用提供的板式 在离线编程界面进行物料分组 编辑设置算法参数点击确定后 程序卡死一分钟以上，多次复现结果一致。

分析：跟踪点击事件代码，整理的时间线如下：

​       1.在projectscenemodel.cpp中的updateGraphicsItem(QGraphicsItem *item, AoiAlgorithm::ProjectElement *component)函数，自身存在频繁递归调用，

​       2.因为多次递归，频繁执行UpdateVisitor visitor(item, q); component->accept(&visitor);

​       3.accept方法会最终调用spiitem.cpp的SpiItem::update()方法进行图形的绘制，从而导致卡顿。
