# 303设备软件卡死问题

## 情况描述

在9.28日下午16：30左右，出现多次卡死情况，最后一次卡死是检测软件点击运行卡死

## 分析日志

1.通过对9.28日下午16：30分左右软件卡死日志分析

最后日志打印时间为16：36分 与FAE提供的卡死时间对应 查看相应代码得知：

输出最后一条日之后，会打印显卡信息，而没有**后续日志输出可知在该位置卡死**

2.通过对9.29上午11.10分左右现场卡死远程分析

 **现场出现编辑软件卡死**的情况，查看资源管理器发现**单核CPU跑满，此时最高占用为nvidia-smi**

**验证：命令行中输入对应命令无法正确输出完整信息**

## 排查显卡问题

### 排查步骤

1. **检查驱动安装情况**：

   - 确保 NVIDIA 驱动已正确安装。使用以下命令检查驱动版本：

     ```Bash
     nvidia-smi --query-gpu=driver_version --format=csv
     ```

   - 如果驱动未正确安装或版本不匹配，重新安装或更新驱动。

2. **检查权限**：

   - 确保具有足够权限的用户身份运行

     ```bash
      sudo nvidia-smi
     ```

3. **检查硬件连接**：

   - 确保 GPU 正确插入到 PCIe 插槽中，并且电源连接正常。

   - 检查 GPU 是否在系统中被正确识别。使用以下命令查看系统中的 PCI 设备：

     ```bash
     lspci | grep -i nvidia
     ```

4. **检查系统日志**：

   - 查看系统日志，查找与 NVIDIA 驱动相关的错误信息。使用以下命令查看日志：

     ```bash
     dmesg | grep -i nvidia
     ```

   - 查看 `/var/log/syslog` 或 `/var/log/messages` 文件中的相关日志。

5. **重启 NVIDIA 驱动**：

   - 尝试重启 NVIDIA 驱动服务：

     ```bash
     sudo systemctl restart nvidia-persistenced
     ```

6. **检查 CUDA 安装情况**：

   - 确保 CUDA 已正确安装，并且版本与驱动兼容。使用以下命令检查 CUDA 版本：

     ```bash
     nvcc --version
     ```
