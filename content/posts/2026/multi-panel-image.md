# 保存多拼板图像功能说明

## 一 . 功能概述

增加功能把每个拼板图片都存起来,并且文件名要符合一定的规则。

## 二 . 功能开关

使用前需要在离线编辑中勾选需要保存的光源

后在检测软件中设置：

以下是开关功能解释:

- 图片名字:选择保存图像文件的文件名规则,可选:

  - 拼板条码,例如: T_sn8899.jpg

  - 时间戳 + 拼板 ID ,例如: T_20250421131908004_1.jpg

  - 拼板条码 + 时间戳,例如: T_sn8899_20250421131908004.jpg

  - 拼板 ID ,例如: T_1.jpg

​	注 1 : T 和 B 分别表示顶面和底面。
​	注 2 :如果选择 拼板条码 有关选项,但无拼板条码或者拼板条码含有 Linux 路径不允许的特殊符号，则文件名会自动换成 时间戳+拼板ID 的形式。
​	注 3 :如果目标位置已经存在同名文件,则新文件会自动增加序号进行存储,例如 T_sn8899(1).jpg 。

- 缩放比:选择压缩图片尺寸的比例,数字越小,图片越清晰,反之则越模糊
- 保存路径:选择图像文件的存储路径,可选:
  - 默认:存储到 /home/用户名/aoi/run/Boards/板式名/日期/时间戳/板面
  - 用户自定义目录:存储到用户指定的目录(通过 选择文件夹 按扭进行选择)

- 通用存储路径:当 保存路径 选择 用户自定义目录 时,可选在用户自定义目录额外增加存储路径,可选项:

  - 用户自定义目录:直接存储文件到用户自定义目录内

  - 用户自定义目录 / 板式名:在用户自定义目录内,按板式名增加一级目录,然后在板式名目录内存储文件

  - 用户自定义目录 / 板式名 / 年 / 月 / 日:在用户自定义目录内,按板式名、年、月、日增加多级目录,然后在目录内存储文件

注:

- 当选择 **默认** 时,通用存储路径功能不起作用。

- 保存的拼板图片会根据FOV拼接，FOV没有拍到的位置不会有图片。
